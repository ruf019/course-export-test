# Собираем страницу

1. Создайте index.html с заголовком и абзацем.
2. Подключите style.css и измените цвет заголовка.
3. Добавьте кнопку и обработчик клика в script.js.
4. Откройте страницу в браузере и проверьте результат.

**Результат:** простая интерактивная страница, в которой есть HTML, CSS и JavaScript.
