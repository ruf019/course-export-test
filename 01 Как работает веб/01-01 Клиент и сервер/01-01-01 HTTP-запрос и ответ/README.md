# HTTP-запрос и ответ

Когда мы открываем страницу, браузер отправляет HTTP-запрос на сервер. Сервер возвращает ответ: код состояния, заголовки и тело.

## Пример

- GET / — запрос главной страницы.
- 200 OK — сервер успешно вернул страницу.
- 404 Not Found — запрошенный ресурс не найден.

**Практика:** откройте инструменты разработчика и найдите запрос документа во вкладке Network.
